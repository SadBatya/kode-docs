## Именование

| Что | Конвенция | Пример |
|-----|-----------|--------|
| Компоненты | PascalCase | `UserCard.tsx` |
| Хуки | camelCase + `use` префикс | `useUserData.ts` |
| Утилиты | camelCase | `formatDate.ts` |
| Типы/Интерфейсы | PascalCase + суффикс | `UserType`, `UserProps` |
| Константы | UPPER_SNAKE_CASE | `MAX_RETRY_COUNT` |
| CSS классы | kebab-case | `user-card__avatar` |

## Структура компонента

```tsx
// UserCard.tsx
import type { FC } from 'react'

interface UserCardProps {
  userId: string
  name: string
  onSelect?: (id: string) => void
}

export const UserCard: FC<UserCardProps> = ({ userId, name, onSelect }) => {
  const handleClick = () => onSelect?.(userId)

  return (
    <div className="rounded-lg border p-4" onClick={handleClick}>
      <h3 className="font-semibold">{name}</h3>
    </div>
  )
}
```

<Callout type="info">
  Экспортируйте компоненты именованным экспортом (не default). Это упрощает рефакторинг и автоимпорт.
</Callout>

## Работа с API

Используем **React Query** для серверного стейта:

```tsx
// hooks/useUser.ts
import { useQuery, useMutation } from '@tanstack/react-query'
import { api } from '@/lib/api'

export const useUser = (userId: string) =>
  useQuery({
    queryKey: ['users', userId],
    queryFn: () => api.users.getById(userId),
    staleTime: 5 * 60 * 1000, // 5 минут
  })

export const useUpdateUser = () =>
  useMutation({
    mutationFn: api.users.update,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['users'] })
    },
  })
```

## Типизация

```tsx
// Всегда типизируйте props явно
interface Props { ... }  // для компонентов
type Config = { ... }    // для объектов конфигурации

// Используйте utility types
type UserPreview = Pick<User, 'id' | 'name' | 'avatar'>
type CreateUserDTO = Omit<User, 'id' | 'createdAt'>

// Не используйте any — используйте unknown + type guard
function processData(data: unknown): User {
  if (!isUser(data)) throw new Error('Invalid user data')
  return data
}
```

## Тестирование

```tsx
// UserCard.test.tsx
import { render, screen, fireEvent } from '@testing-library/react'
import { UserCard } from './UserCard'

describe('UserCard', () => {
  it('вызывает onSelect при клике', () => {
    const onSelect = vi.fn()
    render(<UserCard userId="1" name="Иван" onSelect={onSelect} />)

    fireEvent.click(screen.getByText('Иван'))

    expect(onSelect).toHaveBeenCalledWith('1')
  })
})
```

Правило: **не тестируйте детали реализации** — тестируйте поведение с точки зрения пользователя.
