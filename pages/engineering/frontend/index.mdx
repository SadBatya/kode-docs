# Frontend

**Стек:** React 18 · TypeScript · Next.js · Zustand · React Query · Tailwind CSS

**Slack:** `#team-frontend`  
**Тимлид:** @frontend-lead  
**Репозиторий:** `gitlab.com/your-org/frontend`

## Проекты

| Проект | Описание | URL |
|--------|----------|-----|
| `web-app` | Основное веб-приложение | `app.kode.ru` |
| `admin-panel` | Панель администратора | `admin.kode.ru` |
| `landing` | Маркетинговый сайт | `kode.ru` |
| `design-system` | Компонентная библиотека | npm: `@kode/ui` |

## Стандарты

- **TypeScript Strict Mode** — `strict: true` в tsconfig, никаких `any`
- **Компоненты** — функциональные, без классовых компонентов
- **Стейт** — Zustand для глобального, React Query для серверного, `useState` для локального
- **Стили** — Tailwind CSS + CSS Modules для сложных компонентов
- **Тесты** — Vitest + Testing Library (unit), Playwright (e2e)
- **Линтер** — ESLint + Prettier (конфиг в корне репо)

## Запуск локально

```bash
cd frontend/web-app
cp .env.example .env.local
npm install
npm run dev  # http://localhost:3000
```

## Полезные команды

```bash
npm run dev          # dev-сервер
npm run build        # production build
npm run test         # юнит-тесты
npm run test:e2e     # e2e-тесты (Playwright)
npm run lint         # ESLint
npm run type-check   # TypeScript проверка
npm run storybook    # компоненты в Storybook
```
