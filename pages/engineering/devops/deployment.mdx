# Деплой

## Окружения

| Окружение | Ветка | Триггер | Approvals |
|-----------|-------|---------|-----------|
| `dev` | `develop`, feature-ветки | Авто при merge | — |
| `staging` | `main` | Авто при merge | — |
| `production` | `main` | Ручной | 1 тимлид или DevOps |

## Деплой в production

<Steps>
### Убедитесь, что staging стабилен

Проверьте дашборды в Grafana — ошибки, latency, saturation.

### Запустите деплой в GitLab CI

Перейдите в CI/CD → Pipelines → найдите последний пайплайн на `main` → запустите `deploy-prod` стадию.

### Подтвердите деплой

Менеджер пайплайна или тимлид нажимает «Approve» в интерфейсе GitLab.

### Наблюдайте за деплоем

```bash
# Следите за rollout
kubectl rollout status deployment/user-service -n production

# Или через Grafana — дашборд Deployment Overview
```

### Проверьте health checks

```bash
curl https://api.kode.ru/health
# {"status": "ok", "version": "1.2.3"}
```
</Steps>

## Откат (Rollback)

<Callout type="warning">
  При любом инциденте — сначала откат, потом разбор причин.
</Callout>

<Tabs items={['Kubernetes rollout', 'GitLab Revert']}>
  <Tabs.Tab>
    ```bash
    # Быстрый откат к предыдущей версии
    kubectl rollout undo deployment/user-service -n production

    # Откат к конкретной ревизии
    kubectl rollout history deployment/user-service -n production
    kubectl rollout undo deployment/user-service --to-revision=3 -n production
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    1. Откройте последний MR в GitLab, который деплоился
    2. Нажмите **Revert** → создастся новый MR
    3. Смёрджите его — CI/CD автоматически задеплоит в staging, затем запустите деплой в prod
  </Tabs.Tab>
</Tabs>

## Helm Charts

Все сервисы деплоятся через Helm:

```bash
# Структура
infra/
  charts/
    user-service/
      Chart.yaml
      values.yaml           # дефолтные значения
      values-staging.yaml   # переопределения для staging
      values-prod.yaml      # переопределения для prod
      templates/
        deployment.yaml
        service.yaml
        ingress.yaml

# Деплой вручную (для отладки)
helm upgrade --install user-service ./charts/user-service \
  -f charts/user-service/values-prod.yaml \
  -n production
```

## Feature Flags

Используем **[Unleash](https://unleash.internal.kode.ru)** для feature flags:

```go
// Go
if unleash.IsEnabled("new-payment-flow") {
    // новая логика
}
```

```tsx
// TypeScript
if (useFlag('new-payment-flow')) {
    // новый компонент
}
```

Флаги позволяют деплоить код без немедленного включения функциональности. Это снижает риск деплоя.
