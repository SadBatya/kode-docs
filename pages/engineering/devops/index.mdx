# DevOps

**Стек:** Kubernetes · Terraform · GitLab CI · Helm · Prometheus · Grafana · Loki

**Slack:** `#team-devops`, `#alerts-prod`  
**Тимлид:** @devops-lead  
**Репозиторий:** `gitlab.com/your-org/infra`

## Инфраструктура

| Компонент | Технология | Где |
|-----------|-----------|-----|
| Kubernetes | EKS / GKE | AWS / GCP |
| Container Registry | GitLab Container Registry | GitLab |
| Secrets | HashiCorp Vault | On-premise |
| Monitoring | Prometheus + Grafana | Kubernetes |
| Logging | Loki + Grafana | Kubernetes |
| Tracing | Tempo + OpenTelemetry | Kubernetes |
| IaC | Terraform | `infra/terraform/` |
| Service Mesh | Istio | Kubernetes |

## CI/CD Pipeline

Каждый репозиторий имеет `.gitlab-ci.yml` со следующими стадиями:

```yaml
stages:
  - lint       # golangci-lint / eslint / ktlint
  - test       # unit + integration тесты
  - build      # docker build + push в registry
  - security   # trivy scan, SAST
  - deploy-dev      # авто-деплой в dev
  - deploy-staging  # авто-деплой в staging (только main)
  - deploy-prod     # ручной триггер (только main)
```

<Callout type="info">
  Деплой в production требует ручного одобрения тимлида или DevOps-инженера.
</Callout>

## Мониторинг

- **Дашборды:** Grafana → `grafana.internal.kode.ru`
- **Алерты:** PagerDuty → on-call ротация в `#team-devops`
- **Логи:** Grafana Loki → поиск по `{namespace="production"}`
- **Трейсы:** Grafana Tempo

### On-call

On-call ротация — раз в неделю. Расписание: [PagerDuty](https://kode.pagerduty.com).

При инциденте: следуйте [процедуре реагирования](/processes/incident-response).

## Доступ к Kubernetes

```bash
# Настроить kubeconfig
aws eks update-kubeconfig --name kode-prod --region eu-central-1

# Посмотреть поды в prod
kubectl get pods -n production

# Логи пода
kubectl logs -f deployment/user-service -n production

# Exec в под (только с разрешения тимлида)
kubectl exec -it pod/user-service-xxx -n production -- sh
```

<Callout type="warning">
  Прямой exec в production-поды — исключение, не норма. Логируется и проверяется.
</Callout>
