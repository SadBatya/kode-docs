# Mobile

**Платформы:** iOS (Swift) · Android (Kotlin) · Cross-platform (React Native)

**Slack:** `#team-mobile`  
**Тимлид:** @mobile-lead

## Проекты

| Проект | Платформа | Store |
|--------|-----------|-------|
| `kode-ios` | Swift + UIKit/SwiftUI | App Store |
| `kode-android` | Kotlin + Jetpack Compose | Google Play |
| `kode-rn` | React Native | Оба стора |

## Стандарты

<Tabs items={['iOS', 'Android', 'React Native']}>
  <Tabs.Tab>
    - **Swift** 5.9+, deployment target iOS 16+
    - **Архитектура:** MVVM + Coordinator
    - **Зависимости:** Swift Package Manager (никакого CocoaPods)
    - **UI:** SwiftUI для новых экранов, UIKit для legacy
    - **Тесты:** XCTest, SnapshotTesting для UI
    - **Хранение:** CoreData (локально), Keychain (секреты)

    ```bash
    # Запуск
    open kode-ios.xcworkspace
    # Или через командную строку
    xcodebuild -scheme KodeApp -destination 'platform=iOS Simulator,name=iPhone 15'
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    - **Kotlin** 1.9+, minSdk 26 (Android 8.0)
    - **Архитектура:** MVVM + Clean Architecture
    - **UI:** Jetpack Compose
    - **DI:** Hilt
    - **Async:** Coroutines + Flow
    - **Тесты:** JUnit5, Turbine (для Flow), Espresso (UI)

    ```bash
    # Запуск
    ./gradlew assembleDebug
    ./gradlew installDebug  # на подключённое устройство
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    - **React Native** 0.73+
    - **TypeScript** (strict mode)
    - **Навигация:** React Navigation 6
    - **Стейт:** Zustand
    - **Тесты:** Jest + Testing Library + Detox (e2e)

    ```bash
    npm install
    npx pod-install  # только для iOS
    npm run ios      # симулятор iOS
    npm run android  # эмулятор Android
    ```
  </Tabs.Tab>
</Tabs>

## Релизный процесс

1. Feature branch → MR → code review → merge в `develop`
2. Раз в 2 недели: `develop` → `release/x.y.z`
3. QA-тестирование на release ветке
4. Merge в `main` + тег → автоматический деплой в TestFlight / Internal Testing
5. После approval — релиз в Store

<Callout type="warning">
  Версии в `build.gradle` (Android) и `Info.plist` (iOS) обновляются автоматически в CI. Не меняйте их вручную.
</Callout>
