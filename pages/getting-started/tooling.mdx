# Настройка инструментов

## Обязательные инструменты

| Инструмент | Версия | Установка |
|-----------|--------|-----------|
| Git | ≥ 2.40 | `brew install git` |
| Docker Desktop | Latest | [docker.com](https://docker.com) |
| Node.js | 20 LTS | `brew install node@20` |
| Go | 1.22+ | `brew install go` |
| kubectl | Latest | `brew install kubectl` |
| Helm | ≥ 3.x | `brew install helm` |

## Установка

<Steps>
### Установить Homebrew

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### Установить основные инструменты

```bash
brew install git node@20 go kubectl helm awscli jq yq
brew install --cask docker
```

### Настроить Git

```bash
git config --global user.name "Имя Фамилия"
git config --global user.email "name@kode.ru"
git config --global core.autocrlf input
git config --global init.defaultBranch main
```

### Добавить SSH-ключ в GitLab

```bash
ssh-keygen -t ed25519 -C "name@kode.ru"
cat ~/.ssh/id_ed25519.pub
```

Скопируйте вывод и добавьте в GitLab: **Profile → SSH Keys**.

### Проверить подключение к GitLab

```bash
ssh -T git@gitlab.com
# Welcome to GitLab, @username!
```
</Steps>

## IDE

<Tabs items={['VS Code', 'IntelliJ IDEA / GoLand']}>
  <Tabs.Tab>
    **Обязательные расширения:**

    ```json
    // .vscode/extensions.json (уже есть в репозитории)
    {
      "recommendations": [
        "golang.go",
        "dbaeumer.vscode-eslint",
        "esbenp.prettier-vscode",
        "ms-azuretools.vscode-docker",
        "ms-kubernetes-tools.vscode-kubernetes-tools",
        "hashicorp.terraform",
        "eamodio.gitlens"
      ]
    }
    ```

    Установить все сразу:
    ```bash
    cat .vscode/extensions.json | jq -r '.recommendations[]' | xargs -I {} code --install-extension {}
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    **Плагины:**
    - Go / GoLand (встроено)
    - Terraform and HCL
    - Docker
    - Kubernetes
    - GitLab (для MR прямо из IDE)

    **Настройки:** импортируйте `.editorconfig` из корня репозитория — IDEA подхватит автоматически.
  </Tabs.Tab>
</Tabs>

## Переменные окружения

<Callout type="warning">
  Никогда не коммитьте `.env` файлы. Они добавлены в `.gitignore`, но будьте внимательны.
</Callout>

Шаблоны `.env` файлов хранятся как `.env.example` в каждом репозитории:

```bash
cp .env.example .env
# Заполните значения — спросите у тимлида или смотрите в Vault
```

Секреты хранятся в **HashiCorp Vault**. Доступ:
```bash
export VAULT_ADDR=https://vault.internal.kode.ru
vault login -method=oidc
vault kv get secret/backend/dev
```
